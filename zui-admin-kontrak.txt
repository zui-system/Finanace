KONTRAK DATA ZUI FINANCE <-> ZUI ADMIN
(Zui Admin tersambung langsung ke project Firebase akuntansi-zuisystem lewat blok
"ZUI FINANCE" (jenis: "finance") di config.js Zui Admin.)

0. AKSES ADMIN
   Zui Admin (admin.zuisystem.com) masuk dengan Google sebagai admin.zuisystem@gmail.com.
   isAdmin() di firestore.rules mengizinkan email itu. Admin lain tetap bisa ditambah
   dengan dokumen  admins/{UID-admin}  (isi bebas, mis. {nama:"Budi"}).
   Admin boleh: baca workspaces, baca/tulis billing, planRequests, chats, adminPayments.
   Admin TIDAK bisa membaca ledgers (data pembukuan pelanggan).

1. PERMINTAAN PAKET   koleksi: planRequests/{idBuku}
   Diisi pelanggan (owner) setelah membayar: plan ("pro"|"bisnis"), period ("monthly"|"yearly"),
   status ("pending"), by, email, wsName, at (timestamp),
   cur ("IDR"|"MYR"), amount (harga saat itu), ref (nomor referensi pembayaran).
   Saat admin memproses, update dokumen yang sama:
     status: "approved" atau "rejected"
     decidedAt: serverTimestamp
     note: alasan/catatan singkat (opsional)

2. AKTIVASI PAKET     dokumen: workspaces/{idBuku}/billing/plan
   Tulis:  { plan: "pro"|"bisnis", until: Timestamp }
   until = hari ini + 30 hari (bulanan) atau + 365 hari (tahunan).
   Jika paket masih berlaku, tambahkan dari until yang lama.
   Aplikasi pelanggan langsung berubah (realtime), tanpa muat ulang.
   Untuk menurunkan ke Gratis: hapus dokumen atau isi until dengan tanggal lampau.
   "Bisnis selamanya" = plan "bisnis" dengan until 31 Des 2099.
   Saat mengaktifkan dari Antrean, Zui Admin juga menulis catatan pemasukan
     adminPayments/{auto-id} -> { ws, wsName, plan, period, amount, at }
   { ..., cur, ref } ikut disalin dari permintaan.

2b. HARGA & CARA BAYAR   dokumen: zconfig/pay  (diatur di Zui Admin → Harga → ZUI FINANCE)
   { prices: {pro:{1,12}, bisnis:{1,12}}, pricesMYR: {...}, note, noteMYR, qris, duitnow, wa }
   1 = bulanan, 12 = tahunan. Selama belum disimpan, Finance memakai PL (Rupiah) dan PLM (Ringgit)
   di index.html, dan Zui Admin memakai hargaAwal / hargaAwalMYR di config.js.

3. CHAT
   Ringkasan:  chats/{idBuku}  -> { wsName, email, lastText, lastFrom, lastAt }
               (urutkan dengan lastAt untuk daftar percakapan; lastFrom=="user" = perlu dibalas)
   Pesan:      chats/{idBuku}/messages/{auto-id} -> { from, uid, name, text, at }
   Balasan admin: tambah pesan
       { from:"admin", uid:UID-admin, name:"Zui Admin", text:"...", at:serverTimestamp }
     lalu update chats/{idBuku}.lastFrom = "admin", lastText, lastAt.
   Pelanggan melihat balasan lewat ikon chat di pojok kanan atas (ada angka
   penanda untuk balasan yang belum dibaca).

4. YANG TAMPIL DI LONCENG PELANGGAN
   keputusan permintaan paket, paket/percobaan akan berakhir (7 hari), dan kuota
   transaksi bulanan hampir habis (80%). Balasan admin tampil di ikon chat, bukan
   di lonceng.
